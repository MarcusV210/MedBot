# 🚀 Deploy MedBot in 2 Minutes

## ⚡ SUPER QUICK DEPLOYMENT

### **Step 1: Run the Helper Script**
```bash
python deploy.py
```
*This will open Streamlit Cloud and give you everything you need*

### **Step 2: In the Browser (2 minutes)**
1. **Sign in** with GitHub
2. **Click "New app"**
3. **Copy-paste these values:**
   ```
   Repository: MarcusV210/MedBot
   Branch: Anamay
   Main file path: streamlit_app.py
   ```
4. **Click "Advanced settings"**
5. **In Secrets, paste:**
   ```
   GITHUB_TOKEN = "your_github_token_here"
   ```
6. **Click "Deploy!"**

### **Step 3: Get Your Live URL**
- Wait 2-3 minutes
- You'll get: `https://medbot-anamay.streamlit.app/`
- **DONE!** 🎉
